Blue = city bus stop pole, green = minibus stop pole. Tap a marker to see live arrival countdowns for that pole (same ETA data as the main dashboard, refreshed every ~60s). Note: the government transit APIs only publish arrival-time predictions, not bus GPS coordinates — so this map shows fixed stop locations with live countdowns, not moving bus icons. Pick a route from the list to draw its full path along the roads, with every stop from start to finish.
